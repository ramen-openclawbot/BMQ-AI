Hướng dẫn trạng thái xóa dữ liệu Messenger

Trang công khai, không cần đăng nhập. BMQ không tra cứu trạng thái qua endpoint tương đối trên website này.

Khi Meta gửi callback xóa dữ liệu hợp lệ, BMQ trả về một mã xác nhận / confirmation code và đường dẫn trạng thái chính xác trên Edge Function, dạng:

https://<supabase-functions-origin>/functions/v1/facebook-data-deletion/status?code=<confirmation-code>

Vui lòng mở đúng URL trạng thái được trả về cùng yêu cầu của bạn. URL đó hiển thị trang tiếng Việt tối thiểu với trạng thái và thời điểm xử lý; URL không hiển thị định danh hay nội dung Messenger.

Nếu bạn chỉ có mã xác nhận, hãy liên hệ BMQ để nhận lại đường dẫn trạng thái chính xác.
